## Що таке L-SPIM

Визначальна риса мікроскопії з вибірковим площинним освітленням (SPIM) — ортогональне планарне освітлення фокальної площини (світловий листок). Оскільки в кожен момент часу освітлюється лише тонкий прошарок зразка, істотно зменшується фотознебарвлення та фототоксичність, а оптичне секціонування без збудження флуорофорів поза площиною освітлення підвищує співвідношення сигнал/шум порівняно зі звичайною широкопольною епіфлуоресцентною мікроскопією. У типовій горизонтальній конфігурації зразок підвішується вертикально згори й переміщується крізь світловий листок за допомогою моторизованої платформи.

Для успішної візуалізації великих або оптично неоднорідних зразків [оптичне просвітлення](facility/service-clearing) є обов'язковим етапом підготовки.

_Системи зі світловим листком продукують значні обʼми даних — часто десятки Гб під час безперервної багатоканальної зйомки. Оскільки такі обсяги суттєво перевищують оперативну пам'ять звичайної робочої станції, навіть базова візуалізація, обробка та подальший аналіз стають вузьким місцем в роботі з ними._

## Параметри установки

| Параметр                                          | Значення                                                      |
| ------------------------------------------------- | ------------------------------------------------------------- |
| Об'єктив детекції                                 | Olympus PlaN 10x 0.25                                         |
| Збільшення                                        | 5.56x                                                         |
| Камера                                            | 5320x3032 px (16.1 Мпкс), Basler Ace 2R Pro (a2A5320-23umPRO) |
| Розмір пікселя                                    | 0.493 мкм/px                                                  |
| Поле зору                                         | 2.62x1.49 мм                                                  |
| Максимальний розмір зразка                        | приблизно 5x3x3 мм*                                           |
| Крок z-стека                                      | 16 мкрок/мкм (0.0625 мкм/мкрок)                               |
| Латеральна роздільність, FWHM теор./оцінена       | 1.12 мкм / __2.19 мкм__                                       |
| Аксіальна роздільність, FWHM теор./оцінена        | 11.70 мкм / __3.56 мкм__                                      |
| Лазери збудження                                  | 510 нм, 640 нм                                                |
| Емісійні фільтри                                  | Chroma HQ545/40m, Chroma D620/20m, 700/50m                    |

*Точне обмеження розміру зразка залежить від геометрії та оптичних властивостей конкретного зразка. Доступні два варіанти камери для зйомки: кварцева кювета 10x10 мм із тонкою стінкою та кварцева кювета 10x20 мм із товстою стінкою.
