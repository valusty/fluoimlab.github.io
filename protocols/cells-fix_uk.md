# Підготовка
## Матковий розчин 16% PFA

**Попередження щодо безпеки:** параформальдегід токсичний і належить до ймовірних канцерогенів. Завжди працюйте у сертифікованій витяжній шафі. Використовуйте відповідні засоби індивідуального захисту: рукавички, лабораторний халат, захисні окуляри. Не вдихайте порошок або пари.

[**Відеоінструкція**](https://www.youtube.com/watch?v=ntDN5a9-vWk)

### Матеріали:
| Назва | На 100 мл |
| :--- | :--- |
| Порошок параформальдегіду (PFA) | 16 г (Sigma-Aldrich, каталожний номер: P6148) |
| Деіонізована або дистильована вода (ddH₂O) | ~100 мл |
| 1N (або 1М) гідроксид натрію (NaOH) | ~1–5 крапель :) |
| Плитка з магнітною мішалкою | - |
| Магнітний якір | - |
| Скляна хімічна склянка | V=150 мл |
| Термометр | - |
| Фільтрувальний папір із лійкою або шприцевий фільтр | напр., 0,45 мкм |
| pH-метр (необов'язково) | - |

### Протокол (на 100 мл):
1. **Підготовка:** відміряйте **80 мл** деіонізованої води (ddH₂O) у скляну склянку. Додайте магнітний якір і поставте склянку на плитку у витяжній шафі. Нагрівання: нагрійте воду приблизно до **60 °C\***.
   *\*Примітка: не допускайте перевищення 65–70 °C і в жодному разі не доводьте до кипіння — це руйнує формальдегід і вивільняє небезпечні пари.*
2. **Розчинення:** зважте 16 г порошку параформальдегіду. Додайте порошок у теплу воду за постійного перемішування. Розчин стане дуже каламутним (молочним). Порошок не розчиниться одразу.
3. **Просвітлення (деполімеризація):** продовжуючи перемішувати за **60 °C**, повільно додавайте 1N NaOH по краплях. Додайте 1 краплю, зачекайте хвилину, за потреби додайте наступну. Зазвичай потрібна лише невелика кількість (**1–5 крапель**).
4. Розчин має стати прозорим протягом кількох хвилин, коли середовище злегка залужиться. Щойно розчин просвітлився — негайно припиніть додавати NaOH.
5. **Охолодження та фільтрування:** зніміть склянку з нагріву та дайте розчину охолонути до кімнатної температури.
6. Відфільтруйте розчин, щоб видалити нерозчинені частинки.
7. **Доведення до кінцевого об'єму:** перенесіть розчин у мірний циліндр (або мірну колбу) і додайте деіонізованої води до загального об'єму **100 мл**.
8. **Коригування pH (необов'язково):** перевірте pH. Зазвичай він близький до нейтрального (pH **7,0–7,4**). Якщо для вашого маткового розчину важлива точна величина pH, обережно скоригуйте її розведеною HCl, проте частіше це роблять пізніше, під час розведення до робочої концентрації (наприклад, 4% у PBS).

### Зберігання:
Розлийте 16% матковий розчин на аліквоти в невеликі пробірки (наприклад, 10 мл або 50 мл). Зберігайте за -20 °C для тривалого зберігання (місяці/роки). Розморожуйте аліквоти за потреби. Після розморожування тримайте за +4 °C і використайте протягом кількох днів — тижня (уникайте повторних циклів заморожування-розморожування).

### Оптимізований протокол розведення (4%):
Просто додати 16% розчин формальдегіду до звичайного 1x PBS не зовсім коректно для делікатних клітин (як-от нейронів). Це знизить концентрацію солей, і клітини можуть набрякати.

#### Спосіб 1: для збереження ідеальної морфології
Для цього знадобиться концентрований 10x PBS та вода.

**Формула:**
- 1 частина 16% PFA
- 0,4 частини 10x PBS
- 2,6 частини води (ddH₂O)

**Приклад розрахунку для 10 мл кінцевого розчину:**
- 2,5 мл — 16% PFA (ваш матковий розчин)
- 1,0 мл — 10x PBS (щоб кінцева концентрація солей була 1x)
- 6,5 мл — дистильована вода

Це зберігає фізіологічну осмолярність (~300 мОсм).

#### Спосіб 2: спрощений (якщо є лише звичайний 1x PBS)
Якщо 10x PBS немає, можна взяти звичайний PBS, але концентрація солей буде трохи нижчою за норму (0,75x PBS).

**Формула (розведення 1:4):**
- 1 частина 16% PFA
- 3 частини 1x PBS

**Приклад для 10 мл розчину:**
- 2,5 мл — 16% PFA
- 7,5 мл — 1x PBS

*Недолік: розчин буде гіпотонічним. Для рутинної гістології цього зазвичай достатньо, але для тонких мембранних структур можуть виникнути артефакти.*

# Фіксація клітин
Для фіксації клітин будь-якого типу та в кожному випадку візуалізації (після трансфекції / AB / флуоресцентного забарвлення) знадобиться:

| Назва | Концентрація | V |
| :--- | :--- | :--- |
| **Формальдегід** | **4%** | **1000 мкл/скельце (якщо ви використовуєте 12-лункові планшети або чашку Петрі 35 мм)** |
| **Сахароза** | **4 г/10 мл 4% формальдегіду** | **Розрахуйте та додайте сахарозу до вашого V формальдегіду** |
| **1x PBS** | **-** | **1 мл/скельце** |
| **H₂O дист.** | **-** | **-** |
| **Середовище для заключення (якщо використовуєте предметні скельця)** | **-** | **1 крапля/скельце (VECTASHIELD Antifade Mounting Medium, Vector Laboratories, кат. №: H-1000-10, H-1200-10 з DAPI)** |

| Назва | Примітка |
| :--- | :--- |
| **Піпетка або вакуумний насос (необов'язково)** | **1000 мкл + наконечники** |
| **Шматок парафілму або чашка Петрі** | **1/скельце** |
| **Предметне скло (необов'язково\*)** | **1/скельце** |
| **Пінцет** | **-** |
| **Маркер** | **-** |
| **Рукавички** | **-** |
| **Лак для нігтів (необов'язково\*)** | **будь-який, крім гелевого** |

*\*Примітка: якщо ви плануєте використовувати antifade-середовище / AB / наночастинки тощо, не переносьте скельце на предметне скло. Виконуйте всі маніпуляції в чашці Петрі.*

Скельце з клітинами переносять із 12-лункового планшета (якщо воно було в чашці Петрі — можна одразу починати фіксацію); перед початком приберіть ½ середовища з лунки.

### Хід роботи:
1. Для кожного скельця додайте 500 мкл 4% формальдегіду з сахарозою до залишку середовища в лунці, тримайте в інкубаторі 10 хв \*\*
2. Після цього приберіть увесь розчин із лунки та додайте 500 мкл 4% формальдегіду з сахарозою, тримайте в інкубаторі 10 хв
3. Приберіть\*\*\* розчин формальдегіду;
4. Додайте 500 мкл PBS, залиште на 5 хв;
5. Приберіть PBS і додайте H₂O дист.;
6. Підпишіть предметне скло / чашку Петрі: тип клітин, трансфекція/AB, дата;
7. Якщо використовуєте предметне скло: нанесіть на нього краплю середовища для заключення (невелику). Приберіть H₂O дист. і покладіть скельця на предметне скло клітинами донизу;
8. Через 5 хв нанесіть трохи лаку для нігтів на краї скельця (див. зображення 1);
9. Зберігайте за +4 °C\*\*\*\*.

*\*Примітка: цей крок адаптовано для первинної нейрональної культури, щоб запобігти швидкій вакуолізації. Для менш вибагливих культур можна прибрати все середовище та внести повний об'єм 4% формальдегіду з сахарозою в лунку, залишивши в інкубаторі на 15 хв;*

*\*\*Примітка: можна виконувати в чашці Петрі або на поверхні шматка парафілму;*

*\*\*\*Примітка: для більшої ефективності рекомендується використовувати вакуумний насос;*

*\*\*\*\*Примітка: предметні скельця краще зберігати у спеціальній коробці для скелець.*

# Імуноцитохімічне дослідження

| Назва | Примітка |
| :--- | :--- |
| Буфер для пермеабілізації | від 0,1% до 0,3% Triton X-100 у PBS |
| Блокувальний буфер | **5% BSA** або 5% нормальної сироватки (того самого виду, що й вторинні антитіла, наприклад ослина чи коза) у PBS |
| Антитіла | первинні AB та вторинні AB, кон'юговані з флуорофором |
| Забарвлення ядер (необов'язково) | DAPI або Hoechst 33342 (може входити до складу середовища для заключення) |
| Середовище для заключення | VECTASHIELD, Fluoromount-G, ProLong Gold тощо |

### Хід роботи:
1. **Пермеабілізація**
   - Додайте 0,1–0,3% Triton X-100 у PBS (для нейронів / клітин U83 = 0,1%);
   - Інкубуйте 10 хвилин за кімнатної температури;
   - Відмийте клітини 3 рази PBS (по 5 хв);
   *Порада: пропустіть або скоротіть цей крок, щоб не зруйнувати структуру мембрани, якщо досліджуються мембранозв'язані поверхневі білки.*
2. **Блокування**
   - Додайте блокувальний буфер (наприклад, 5% BSA у PBS);
   - Інкубуйте 30–60 хвилин за кімнатної температури;
   *Призначення: блокує сайти неспецифічного зв'язування та зменшує фоновий сигнал.*
3. **Інкубація з первинними антитілами**
   - Розведіть первинні антитіла в блокувальному буфері згідно з інструкцією виробника (зазвичай від 1:100 до 1:1000);
   - **Варіант A (найкращий для специфічного зв'язування):** інкубуйте протягом ночі за +4 °C у вологій камері;
   - **Варіант B (швидший):** інкубуйте 1–2 години за кімнатної температури;
   - Після інкубації приберіть розчин антитіл;
   - Відмийте клітини 3 рази PBS (по 5–10 хв), щоб видалити незв'язані антитіла.
4. **Інкубація з вторинними антитілами**
   - Починаючи з цього кроку тримайте зразки в темряві;
   - Розведіть вторинні антитіла в блокувальному буфері (зазвичай 1:500 або 1:1000);
   - Інкубуйте 1 годину за кімнатної температури в темряві;
   - Відмийте клітини 3 рази PBS (по 5–10 хв).
5. **Дофарбовування (ядра) [необов'язково]**
   - Додайте DAPI (0,1–1 мкг/мл у PBS) на 1–5 хвилин;
   - Швидко сполосніть PBS;
   *Примітка: багато середовищ для заключення вже містять DAPI — у такому разі цей крок можна пропустити.*
6. **Заключення**
   - Нанесіть краплю середовища для заключення на предметне скло;
   - Обережно візьміть покривне скельце пінцетом;
   - Переверніть скельце (клітинами донизу) і покладіть на краплю середовища;
   *Уникайте бульбашок повітря. Дайте висохнути протягом ночі в темряві перед зйомкою.*
